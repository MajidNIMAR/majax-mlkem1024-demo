# Support

Public questions about building, testing and integrating this repository may be
opened as GitHub issues. Use the supplied issue form and include the exact
revision, platform, command and complete non-sensitive error output.

This repository does not provide support for Majax accounts, production
deployments or private infrastructure. It also does not provide cryptographic
certification for downstream systems.

Suspected vulnerabilities must use GitHub private security advisories as
described in `SECURITY.md`. Do not attach credentials, production data or secret
material to a public or private report.
